The toy shop, built five ways

Every build compiles the same source files. Only the entry and the bundler settings differ, and each mirrors its framework: Next.js makes every page a webpack entry that depends on _app; vinext gives Rolldown one client entry that loads _app and each page with import(). The toy has no UI: each module is a lookup table of a fixed size, so the outputs show where code goes, nothing else.

The two entries

// webpack, as Next.js 16.4 sets it up
entry: {
  main: "src/main.js",
  "pages/_app": { import: "src/pages/_app.js", dependOn: "main" },
  "pages/home": { import: "src/pages/home.js", dependOn: "pages/_app" },
  "pages/product": { … dependOn: "pages/_app" },
  "pages/cart": { … dependOn: "pages/_app" },
}
splitChunks: { framework, lib (> 160 KB), minSize: 20000, maxInitialRequests: 25 }
// Rolldown, as vinext 1.4 sets it up (src/client-entry.js)
const pageLoaders = {
  "/": () => import("./pages/home.js"),
  "/product": () => import("./pages/product.js"),
  "/cart": () => import("./pages/cart.js"),
};
const appLoader = () => import("./pages/_app.js");
codeSplitting: { groups: [framework] }   // no size floor

Full settings: build.mjs. The source is generated by make-app.mjs.
