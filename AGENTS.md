# AGENTS.md

Static explainer page, dark theme. No build step for the page; `demo/` builds the toy app (see README).

## Structure

- `index.html`: hero, sections in page order `#s1` (01 why split), `#s4` (02 decision tree `#cssfloor`, facts), `#snotice` (03 `#race`), `#s2` (04 toy shop graph), `#s3` (05 step figure `#pack`), `#sprio` (06 loading priorities, `#wf`), `#s5` (07 fixes, `#rg`), About footer.
- `styles.css`: tokens on `:root`. `--wp` webpack, `--rd` Rolldown, `--s-*` one color per importer set in the toy.
- `main.js`: `MODULES` (toy sizes, importers, set color), `STEPS` (captions per step), lanes built from `window.TOY`.
- `data.js`: generated by `demo/page-data.mjs`, do not edit.
- `grouping.js`: generated by `demo/grouping-data.mjs` (reads the real builds from disk), do not edit.

## `#cssfloor` data (`demo/grouping-data.mjs`)

Run `node demo/grouping-data.mjs`; it prints the counts below. Product page = build-manifest pages `/_app` + `/product/[titleAndProductId]`.

- **HTML counts.** webpack: the manifest's chunks plus polyfills, `_buildManifest.js` and `_ssgManifest.js` (54 + 3 = 57 scripts, 6 stylesheets). Rolldown: the client entry, `_app` and the page plus their static imports in `.vite/manifest.json`, and those chunks' CSS (PR #4726: 189 / 169, vinext 1.4.5: 576 / 145).
- **Chunks.** The build manifest lists each chunk's files as stylesheet, then script; a chunk can hold only CSS.
- **webpack groups (dots)** are the non-entry chunks of the build with both rules off (`isomorph-cssfloor/.css-floor/both`): 262, 74 with CSS (the other 2 of the 76 stylesheets belong to `_app` and the page). Their modules are found in other builds by webpack's deterministic module ids (keys of `self.webpackChunk_N_E.push`), CSS by the source files in the stylesheet's source map. A group lands where most of its bytes land.
- **Path through the tree.** "own file": the group is the largest group (matching file types) in a shared chunk of the normal build. Else "merged into another file" if it has a file of its own in the build with only the 20 KB rule (`req300`), so the 25-file cap took it away. Else "copied into bigger files" (20 KB rule). Result: 200 copied (67 with CSS), 15 merged (1 with CSS; 4 of the 15 land in the page's own file), 47 own files (6 with CSS); the own files add 47 scripts and 4 stylesheets.
- **Start files.** webpack 10 scripts / 2 stylesheets: runtime, framework, main, `_app`, the page, polyfills, the two manifest files, and two shared chunks whose code the both-off build keeps in the page's own file. 10 + 47 = 57, 2 + 4 = 6. Rolldown 3 / 2 (entry, `_app`, page); every other chunk is one own file: 3 + 186 = 189, 2 + 167 = 169 (1.4.5: 3 + 573 = 576, 2 + 143 = 145).
- The figure shows no group sizes: webpack measures the 20 KB before minifying, so file bytes would not match the rule.
