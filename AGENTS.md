# AGENTS.md

Static explainer page, dark theme. No build step for the page; `demo/` builds the toy app (see README).

## Structure

- `index.html`: hero, sections `#s1` (why split), `#s2` (toy shop graph), `#s3` (step figure `#pack`), `#s4` (large app: `#scale`, facts, `#cssfloor`, `#race`), `#sprio` (loading priorities, `#wf`), `#s5` (fixes, `#rg`), `#spatch` (patched Rolldown, `#patch`; branch `rolldown-patch` only), About footer.
- `styles.css`: tokens on `:root`. `--wp` webpack, `--rd` Rolldown, `--s-*` one color per importer set in the toy.
- `main.js`: `MODULES` (toy sizes, importers, set color), `STEPS` (captions per step), lanes built from `window.TOY`.
- `data.js`: generated by `demo/page-data.mjs`, do not edit.

## Figures

| Id | What | Data |
|---|---|---|
| `#graph` | toy modules with importers | `MODULES` in main.js |
| `#pack` | step figure: each module lands in webpack's and Rolldown's files for the product page | `data.js` (real build output) |
| `#scale` | 55 vs 576 squares | real app |
| `#cssfloor` | three shared components: where their JS and CSS land; webpack's 20 KB CSS floor vs one stylesheet per chunk; 6 vs 169 stylesheets | real app (webpack build vs vinext PR #4726 build), `cssFloor()` in main.js |
| `#race` | first paint / page ready (React hydrated) bars, webpack vs vinext 1.4.5 | real app, iPhone 13 profile, 4G, median of 20 runs |
| `#wf` | animated download waterfall, both builds on one time axis, rows grouped by priority | `waterfall.js`: the run closest to the medians (first paint, largest paint, ready) per build, real app, iPhone 13 profile, 4G, 100 streams (type and timing only) |
| `#rg` | route-grouping outcome | real app |
| `#patch` | toy product page per build: scripts, CSS files, extra copies, CSS order | `demo/result.json` (written by hand into the table) |

`?step=N` opens `#pack` at step N (0–15); arrows step, space plays.
